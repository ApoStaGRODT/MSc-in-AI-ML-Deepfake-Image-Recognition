# Deepfake Image Recognition using Deep Learning.

## MSc in AI Demokritos Deep Learning Course


This project investigates deep learning approaches to deepfake image detection, progressing from a hand-crafted feature baseline through custom CNN architectures to fine-tuned pretrained models. Each stage isolates a specific design choice such as feature representation, network architecture, and transfer learning in order to understand what actually drives detection performance. A final cross-distribution test then examines whether the resulting models learned general deepfake artifacts or merely the signatures of the specific generation method they were trained on.
